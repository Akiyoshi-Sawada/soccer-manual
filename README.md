# サッカー指導者教本

ジュニアサッカー（U-6 / U-8 / U-10）の指導者のための教本です。
「なぜそのプレーなのか」を説明できる指導者になるための、チームの共通言語を目指しています。

## 内容（第0章〜第8章）

| 部 | 章 | 内容 |
|---|---|---|
| 序 | 第0章 | 用語集・教本全体の構造 |
| 第1部 ゲームを理解する | 第1章 | サッカーとは何か |
| | 第2章 | ゲームにおける原理原則（3ゾーン×4局面） |
| 第2部 ゲームを解決する | 第3章 | 個人戦術（認知・判断） |
| | 第4章 | グループ戦術（2〜3人の関係） |
| | 第5章 | チーム戦術 |
| | 第6章 | 技術（25項目・種類別まで詳細に） |
| 第3部 再現する | 第7章 | トレーニング（設計原則） |
| 第4部 伝える | 第8章 | コーチング（観察・介入・ことば・試合） |

## 特長

- **図解**：全項目にオーガナイズ図・状況図つき
- **3視点アニメーション**：技術の動きを「真横／斜め後ろ45°／後ろから」の3視点で同時再生（65本以上）。プレーの前後の文脈つき
- **章どうしの接続**：判断（第3章）と技術（第6章）の線引き、試合→練習の循環（第7・8章）など、章をまたぐ参照を明記
- **年代の目安**：全項目にU-6 / U-8 / U-10の目安を記載
- **単一HTML**：このページだけで完結。オフライン保存でも動作します

## 閲覧方法

ブラウザで開くだけです。スマートフォン推奨（iPhone Safari / Android Chrome で動作確認）。
左上のメニューから章・項目へ移動できます。各ページ末尾の「NEXT」ボタンで順に読み進められます。

チーム内・指導者仲間での共有を歓迎します。
